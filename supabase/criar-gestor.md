# Como criar o acesso do gestor

O cadastro pelo app não existe de propósito. A conta é criada à mão:

1. Supabase > Authentication > Sign In / Providers: desligue **Allow new users to sign up**.
2. Supabase > Authentication > Users > **Add user** > **Create new user**.
3. Informe o e-mail do gestor e uma senha forte, marque **Auto Confirm User**.
4. Passe a senha para o gestor por um canal seguro (pessoalmente ou ligação), nunca por print.
